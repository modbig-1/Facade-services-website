# Facade Services Ltd. — Professional Website

A complete, modern, mobile-responsive single-page website for **Facade Services Ltd.** — professional window & façade cleaning.

## Contents

| File | Purpose |
|------|---------|
| `index.html` | Main page structure & content |
| `styles.css` | Full styling (responsive, modern design) |
| `script.js` | Mobile menu, form → WhatsApp, year, scroll effects |

## Features

- **Sticky header** with logo, navigation & Free Quote CTA
- **Hero section** matching the flyer messaging: “Sparkling Views. Impeccable Clean.”
- **7 service cards**: External, Internal, Post-Construction, Commercial, Residential, Townhouses & Apartments, Malls & Retail
- **Why Choose Us** section with the 5 trust points from the flyer
- **Property types** showcase
- **Strong CTA banner** with phone number
- **Contact / Free Quote form** that opens WhatsApp with a pre-filled message (perfect for Kenya)
- **Footer** with links, contact details & tagline
- Fully **responsive** (desktop → tablet → mobile)
- Colour palette taken from the flyer (navy + gold)

## How to Use

1. Open `index.html` in any modern browser to preview.
2. To publish: upload the whole folder to any web host (Netlify, Vercel, cPanel, GitHub Pages, etc.).
3. Optional improvements:
   - Replace the gradient property images with real photos of your work.
   - Connect the form to an email service (Formspree, EmailJS, or your own backend) instead of / in addition to WhatsApp.
   - Add Google Maps embed for service area.
   - Add real Google Reviews / testimonials.

## Design Notes

Built following best practices from leading window-cleaning websites:
- Phone number & Free Quote CTA always visible
- Clear value proposition above the fold
- Trust signals (safety, spotless results, on-time, satisfaction)
- Separate paths for commercial vs residential messaging
- Fast, clean, professional look that converts visitors into calls/quotes
